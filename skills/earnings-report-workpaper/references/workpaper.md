# 底稿规范

以用户确认的 Word 为准。默认四个 sheet：事件、投资要点第一段、投资要点第二段、投资要点第三段。投资建议、评级、风险提示等非正文仍保留来源草稿或观点属性，默认不纳入这四张截图表；用户另有要求再扩展。

每张表顶部放整段正文锚点与核心来源截图。下方每组左侧一句或一个信息点，右侧对应原始材料截图，横向对齐，多来源可上下叠放，组间黄色横条。默认单句块；整段模式必须灰色突出对应句子。

右侧必须是原始来源页截图，不用自己写的摘要卡片冒充。HTML 在离线副本上高亮；PDF/图片按明确坐标裁剪，并人工确认重点清晰。PDF 坐标采用页面 2 倍渲染后的像素 `[x,y,width,height]`，page_index 从 0 开始。裁剪本身不等于高亮，需要高亮时提供保留原文的预标注图片。

## 英文原材料的中文辅助翻译

英文或中英混合来源采用三栏：左侧研报正文，中间原文截图，右侧“中文译文（辅助翻译）”。概览和每个逐句对照组都显示对应译文；中文来源没有译文时保留原来的两栏。一个正文对应多个来源时，每个来源单独配译文，不合并成研报观点。

agent 先从截图区域提取原文至 source_excerpt，再忠实翻译至 translation_zh，并设置 source_language=en（中英混合用 mixed）。翻译任务由使用 Skill 的模型执行，脚本只排版、检查缺项，不额外调用翻译 API。英文来源缺译文时报错。旧配置未标语言仍可运行，但更新旧底稿时必须先识别来源语言并补齐英文译文。

翻译应覆盖支持结论的完整句子或表格项，保留否定、条件、may/expect 等不确定措辞以及期间、币种、单位、GAAP/Non-GAAP。不得将公司预计翻译成已经实现，也不能把 5 percentage points 写成增长 5%。必要时保留英文产品名。不能从研报正文反推译文，不能用摘要或研究判断替代翻译。看不清或提取不全时先补清晰来源，不猜译。

检查原文截图与译文逐条对应、数字口径一致、长译文不遮挡下一组。译文是审核辅助，原始证据及出处仍保留。仅同一张表包含英文证据时扩展译文栏；宽表宜在 Excel 中缩放查看，打印需检查字号。

保留行名、列标题、期间与少量上下文，不能只截单个数字。来源标签以文件名为主，有真实页码才写页码，计算说明放来源图下。多页多出处应分 evidence，不把相距很远的关键词裁成整页长图。

不要设置 allow_unhighlighted/allow_missing_terms 来掩盖定位失败。确需例外时说明原因并取得用户接受。HTML 跨标签关键词可能无法自动命中，应改用较短且完整的原文片段或人工截图，不能制造原文。

正式输出单个版本化 Excel；配置、图片、manifest 放用户项目的过程目录。生成后检查所有 sheet，必要时用 Excel 或 LibreOffice 导出 PDF，再看遮挡、字号、空白页、图像清晰度和左右对应。结构检查不替代视觉与内容审阅。
