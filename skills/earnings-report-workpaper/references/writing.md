# 写作规则

默认适用于中文 AI/科技公司财报点评，可被用户的正式规范覆盖。

- 标题通常为“本季结果＋中期驱动”，避免把并列事实写成强因果。
- 正文：事件段＋三个投资要点＋投资建议＋风险提示。事件段 2—3 句，精选营收、同比、利润/EPS、核心 KPI、指引，尽量不超过六个核心数字。投资要点通常每段 180—260 字，长度服从信息量。
- 每段先写业务变化和数据，再写对收入、利润率、订单或商业化的含义。AI 内容应落到产品、场景、客户、用量、ARR 或订单；没有量化材料就降低判断强度，不编造。
- 成稿通常用“公司”转述；电话会与公司展望的来源类型在映射中保留。公司指引不能写成已经实现的事实。
- 直接陈述事实，减少“公司披露/体现/反映/值得注意的是”等重复前缀。不使用“获得动能、费用纪律、价值捕获”等翻译腔；技术名词需解释实际业务场景。
- 避免后续跟踪清单式收尾。投资建议仅使用用户确认的评级和研究观点，不能默认推荐或把上调指引机械等同于推荐理由。未提供评级时先写观点草稿并标记待用户确认。
- 风险提示通常 3—5 项，包含行业风险和公司特定风险；AI 商业化风险仅在与公司相关时加入。
- 同比/环比、财年/自然年、收入/ARR/订单、GAAP/Non-GAAP 不混用；自行计算注明分子分母、单位、期间与舍入。
- 判断强度与证据匹配。重要归纳尽量由两个独立事实支持；没有足够证据就改弱或删除。

## Markdown 输入格式

Word 填充器要求一级标题，以及 `## 事件`、`## 投资要点`、`## 投资建议`、`## 风险提示`。投资要点下每个标题用 `▌` 起头，标题和正文之间留空行。示例由 `make_demo.py` 生成，全部为虚构数据。
