# 批量、返修和跨电脑交接

## 批量与独立审阅

仅在用户或任务明确要求/授权并行时派发。按公司或独立文件分配所有权，记录主控与执行任务ID、模型/推理设置、回报要求；数量服从工具实际能力，不把某次并发数或模型写成Skill固定要求。配置意图与实际生效分开记录。

执行者只改自己范围，不撤销他人修改；制作与独立审阅分开。审阅者绑定准确Word/Excel路径及哈希，按实际交付件核验；作者返修另存版本，再由审阅者定向关闭问题。共用机制问题由主控统一修复，用无关虚构样例验证，不为单个真实公司写特判。

用户已授权主控复核后连续制作时，保存授权原话、适用范围及当前Word的复核记录；不能自动勾选用户逐篇确认。无人值守时复用现有环境，权限/依赖阻塞报主控并继续独立部分，不分散申请重复授权或规避权限限制。

## 最终版本

维护唯一最终清单：公司、报告期、MD/Word/Excel、生成配置、来源映射、复核记录及哈希。取件与汇总都读该清单，不能按文件名最大版本或更新时间猜，也不能在后续汇总时回退到首轮通过版本。发生返修后同时核对核验说明、概览、来源编号、译文图及预览；不能只改一处单元格。

模板刷新即使不改正文也改变Word哈希。逐字确认正文一致后，按目标审核制度记录旧Word到新Word的关联；需要再生成底稿时另存新版本。有正文变化则补证据并复核。复用已有用户授权，不因技术版本变化新增无必要确认。

## 迁移或上传交接

包内包含最终成稿、一手来源、当前配置及必要审阅记录；保留历史版本时明确当前取件入口。用相对路径清单，列必要Skill、模板和运行依赖；历史Mac绝对路径标为来源记录，不当Windows可执行路径。最新机构模板与原制作模板分清。

移除虚拟环境、Office用户缓存与登录凭据，业务文件哈希保持。解压到另一目录后检查最终文件、配置来源、索引链接和必要运行路径；迁移目录测试不等于Windows实机验证。
